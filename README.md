# Программный комплекс предиктивного мониторинга и адаптивной оптимизации тепловых режимов конвейерных зерносушилок

## Аннотация
Данный проект представляет собой программную реализацию интеллектуальной системы мониторинга и управления процессом дегидратации зерновых культур. В основе решения лежит математическое моделирование физических процессов тепломассообмена и применение методов теории информации для повышения достоверности сенсорных данных. Система ориентирована на повышение энергоэффективности промышленного оборудования компании «Агромиг» и минимизацию термического повреждения продукции.

## Актуальность
Процесс послеуборочной сушки зерна характеризуется высокой энергоемкостью и нелинейной зависимостью качества конечного продукта от динамики температурных режимов. Традиционные системы управления, использующие статические пороговые значения, не учитывают тепловую инерцию и стохастическую природу внешних возмущающих воздействий. Разработанный комплекс позволяет автоматизировать принятие решений на основе предиктивного анализа состояния системы.

## Научно-техническая база
Проект интегрирует следующие научно-инженерные подходы:
1. **Численное моделирование:** Решение связанной системы дифференциальных уравнений теплопроводности и массопереноса с использованием метода Рунге-Кутты четвертого порядка.
2. **Адаптивная фильтрация:** Алгоритм первичной обработки сигналов, использующий меру информационной энтропии Шеннона для динамической настройки коэффициентов сглаживания экспоненциального среднего.
3. **Объектно-ориентированное проектирование:** Архитектура системы построена на принципах SOLID, что обеспечивает высокую масштабируемость и возможность интеграции с реальными аппаратными интерфейсами (Industrial IoT).

## Основные функциональные модули
- **Hardware Emulator:** Программный имитатор физических процессов, моделирующий динамику изменения температуры зерна и влажности с учетом скрытой теплоты парообразования.
- **Signal Processor:** Модуль статистической обработки данных, выполняющий очистку сигналов от аппаратных шумов и оценку информационной энтропии потока данных.
- **Decision Engine:** Экспертная система, осуществляющая сопоставление очищенных метрик с целевыми профилями культур и формирующая управляющие директивы.
- **Persistence Layer:** Слой взаимодействия с реляционной базой данных PostgreSQL для ведения структурированных журналов производственных сессий и телеметрии.

## Технологический стек
- **Язык программирования:** Python 3.10+
- **Система управления базами данных:** PostgreSQL
- **Библиотеки взаимодействия с БД:** Psycopg2
- **Типизация:** Строгая статическая типизация (Typing, Dataclasses)

## Инструкция по развертыванию

### 1. Подготовка инфраструктуры данных
Для инициализации структуры базы данных необходимо выполнить SQL-скрипт `schema.sql`, который создаст требуемые таблицы и нормализованные связи:
```bash
psql -h localhost -U postgres -d agromig_db -f schema.sql
```

### 2. Установка зависимостей
Установка необходимых программных интерфейсов производится через менеджер пакетов pip:
```bash
pip install -r requirements.txt
```

### 3. Конфигурация
Параметры подключения к базе данных (DSN) настраиваются в файле `src/main.py` или через переменные окружения операционной системы.

### 4. Запуск системы
Исполнение главного программного модуля:
```bash
python src/main.py
```

## Формат выходных данных
Система осуществляет вывод технологических логов в стандартизированном виде:
- **Метрики:** текущие показатели температуры и влажности в реальном времени.
- **Директивы:** детализированные инструкции по изменению скорости конвейера или параметров теплоносителя при обнаружении девиаций.
